omg.datamodule.structure.Structure#

class omg.datamodule.structure.Structure(cell: Tensor, atomic_numbers: Tensor, pos: Tensor, property_dict: dict[str, Any] | None = None, metadata: dict[str, Any] | None = None, pos_is_fractional: bool = False)[source]#

Storage for a single crystalline structure of atoms.

The structure is represented by its cell, atom numbers, and Cartesian or fractional atom coordinates. Additionally, one can store arbitrary properties and metadata associated with the structure in this class.

This class also provides methods to change the representation of the structure. It is possible to convert the Cartesian atom coordinates to fractional coordinates and vice versa, and to Niggli reduce the structure.

Parameters:

  • cell (torch.Tensor) – A 3x3 matrix of the lattice vectors. The [i, j]-th element is the jth Cartesian coordinate of the ith unit vector.

  • atomic_numbers (torch.Tensor) – A vector of N integers giving the atomic numbers of the atoms, where N is the number of atoms.

  • pos (torch.Tensor) – A Nx3 matrix of the fractional or Cartesian coordinates of the atoms in the structure, where N is the number of atoms.

  • property_dict (Optional[dict[str, Any]]) – An optional dictionary of properties associated with the structure. Defaults to None.

  • metadata (Optional[dict[str, Any]]) – An optional dictionary of metadata associated with the structure. Defaults to None.

  • pos_is_fractional (bool) – Whether the given atomic positions are in fractional coordinates. Defaults to False.

Raises:

AssertionError – If the cell is not a 3x3 matrix or if the pos is not a Nx3 matrix, where N is the length of species.
