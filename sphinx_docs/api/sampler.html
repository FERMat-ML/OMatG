Sampler#

The omg.sampler module provides base distributions for crystal generation.

Module Overview#

Samplers generate initial random structures (\(x_0\)) that are evolved to data samples through stochastic interpolants. The module includes:

  • Independent sampler combining position, cell, and species distributions

  • Position distributions (uniform, normal, mirror)

  • Cell/lattice distributions (uniform, informed, normal, mirror)

  • Species distributions (mask, uniform, mirror)

  • Minimum permutation distance utilities

Main Classes#

independent_sampler.IndependentSampler

Samplers that independently sample species, positions and cells from given base distributions.

sampler.Sampler

Abstract base class for all samplers that sample structures from the base distribution that will be connected to structures from the training data via stochastic interpolants.

Position Distributions#

UniformPositionDistribution

Position base distribution that samples fractional coordinates between 0 and 1 using a uniform distribution.

NormalPositionDistribution

Base distribution that samples fractional positions from a normal distribution with given mean and standard deviation.

MirrorPosition

Base distribution that just mirrors the given positions of a single structure.

Cell Distributions#

InformedLatticeDistribution

Informed base lattice distribution for different datasets as used by FlowMM (see https://arxiv.org/abs/2406.04713).

NormalCellDistribution

Base distribution that samples entries of cell vectors from a normal distribution with given mean and standard deviation.

MirrorCell

Base distribution that just mirrors the given cell of a single structure.

Species Distributions#

MaskSpeciesDistribution

Base distribution for species that always returns the same masking token for all atoms.

UniformSpeciesDistribution

Base distribution for species that samples integers uniformly from a given range of atomic numbers.

MirrorSpecies

Base distribution that just mirrors the given species of a single structure.

sample_p_0(x_1: OMGData) → OMGData[source]#

Sample the base distribution given a batch of structures from the training data.

The returned OMGData represents a batch of structures sampled from the base distribution.

The number of atoms in each sampled structure is the same as in the corresponding structure in the input OMGData x_1. For the positions, they choose the same representation (cartesian or fractional) as in the input OMGData x_1.

Parameters:

x_1 (OMGData) – A batch of structures from the training distribution.

Returns:

A batch of structures sampled from the base distribution.

Cell Distributions#

class omg.sampler.cell_distributions.InformedLatticeDistribution(dataset_name: str)[source]#

Bases: CellDistribution

Informed base lattice distribution for different datasets as used by FlowMM (see https://arxiv.org/abs/2406.04713).

This distribution samples lattice vectors based on log-normal distributions for the lengths of the lattice vectors and uniform distributions for the angles between the lattice vectors. The parameters of the log-normal distributions are taken from FlowMM’s fits to the training datasets (see also fit_lattice in OMGTrainer).

Parameters:

dataset_name (str) – Name of the dataset. Can be one of “carbon_24”, “mp_20”, “mpts_52”, “perov_5”, and “alex_mp_20”.

Raises:

ValueError – If the dataset name is unknown.
